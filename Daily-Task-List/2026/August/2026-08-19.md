v3 现在的流程
```
POST /task/create/slides_render
  └─ TaskService.submit          建任务，后台跑
      └─ RenderService.run_task   状态机：RUNNING → SUCCEEDED / FAILED
          └─ RenderService.run    组装 → 渲染 → 产物入 MinIO
              └─ InProcessRenderBackend.render
```

后端里是五步:

① 备料    load_template() 读模板 → 建临时项目目录
          svg_output/  images/  validation/  exports/  notes/
          模板素材拷进 images/，SlideContent.notes 写进 notes/
                    ↓
② 逐页    Semaphore(6) 限并发，每页一个协程：
            调模型 → 抠出 SVG → 落盘 → 单页质检
            有 blocking 就把报错原文回灌，最多 3 轮
          任一页最终没过 → 整次渲染失败，不出缺页的 pptx
                    ↓
③ 整体质检 svg_quality_checker.py <项目> --quick-generate --stage final --json
          产出 validation/svg_quality_report.json（导出器的闸门要读它）
                    ↓
④ 导出    svg_to_pptx.py <项目> --quick-generate --with-notes -o ...
                    ↓
⑤ 收产物  读 pptx → 数页数核对 → 读回 20 张 SVG

③④ 走子进程调 third_party/ppt-master 里 vendored 的脚本,不是 import。
