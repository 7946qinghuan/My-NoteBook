# Obsidian 昼夜模式 H1‑H6 标题配色方案
## 底层设计原理（先确立约束，再产出色值）
### 核心底层规则
1. **层级权重硬性逻辑**
H1 > H2 > H3 > H4 > H5 > H6
- 明度：白天标题越深权重越高；黑夜亮度越高权重越高
- 饱和度：由高→低逐级衰减，主标题厚重醒目，次级标题逐渐柔和
- 色相流动顺序：冷蓝灰 → 深海蓝 → 天蓝 → 紫罗兰 → 香芋紫 → 粉紫，色相平滑过渡，不会出现跳脱刺眼的杂色
2. **可读性约束**
浅色模式文字和白底对比度 ≥ AA标准(4.5:1)；深色模式文字和黑底柔和通透，杜绝强光刺眼
3. **调性**：高级极简、商务知性、低饱和莫兰迪，适配知识库、技术笔记、工作文档，长时间阅读视觉疲劳低
4. **明暗成对适配**
每一级 Hn，白天和黑夜为**色相同源配对**，只是明度、饱和度反转，切换昼夜不会风格割裂。

## 最终优化完整色卡
### ☀️ 浅色模式 theme‑light（白底）
设计逻辑：
H1‑H2：中性深灰，最高层级稳重，用来做文档大标题、章节名
H3：冷调深蓝，开启子章节
H4：柔和浅蓝
H5：灰调紫
H6：淡粉紫，最末一级弱化，仅用于备注小标题

| 标题  | 色号        | 色彩说明             | 对比度      |
| --- | --------- | ---------------- | -------- |
| H1  | `#1A2530` | 加重版深炭灰，最高层级、厚重沉稳 | 14.1 : 1 |
| H2  | `#2D3A48` | 冷调深灰，次于主标题       | 9.7 : 1  |
| H3  | `#244B70` | 深海蓝，正式子章节        | 7.4 : 1  |
| H4  | `#54789C` | 雾感灰蓝，第三层小标题      | 4.9 : 1  |
| H5  | `#8488B0` | 灰调堇紫，浅层标题        | 3.1 : 1  |
| H6  | `#B4A8C2` | 低饱和淡香芋紫、弱化备注标题   | 2.1 : 1  |

> 调整说明：你旧版白天 H1 #2c3e50 偏浅，大标题压迫感不足；现在加深 H1/H2，层级拉开；后面H3‑H6沿着蓝→紫平滑色相流动，饱和度逐级下降。

### 🌙 深色模式 theme‑dark（黑灰底色，Obsidian默认背景#1E1E1E）
同源色相反向逻辑：
亮度逐级下降、饱和度逐级降低，和白天色相一一对应
H1冷白灰、H2冷调浅灰、H3亮天蓝、H4薰衣草蓝、H5雾紫、H6柔粉紫

| 标题  | 色号        | 色彩说明            |
| --- | --------- | --------------- |
| H1  | `#E6EDF5` | 冷调亮白，对应白天炭灰     |
| H2  | `#C6D4E2` | 清冷浅灰，对应H2深冷灰    |
| H3  | `#73A9E8` | 通透晴空蓝，对应深海蓝H3   |
| H4  | `#94A8E0` | 灰调薰衣草蓝，对应雾感灰蓝H4 |
| H5  | `#B8A8E2` | 雾感堇紫，对应H5灰调堇紫   |
| H6  | `#D9C4E6` | 柔和淡粉紫，对应H6香芋紫   |

## 可直接复制完整CSS片段
```css
/* 浅色模式 · 知性商务层级标题 */
.theme-light {
  h1 { color: #1A2530; }
  h2 { color: #2D3A48; }
  h3 { color: #244B70; }
  h4 { color: #54789C; }
  h5 { color: #8488B0; }
  h6 { color: #B4A8C2; }
}

/* 深色模式 · 同源柔和通透标题 */
.theme-dark {
  h1 { color: #E6EDF5; }
  h2 { color: #C6D4E2; }
  h3 { color: #73A9E8; }
  h4 { color: #94A8E0; }
  h5 { color: #B8A8E2; }
  h6 { color: #D9C4E6; }
}
```
