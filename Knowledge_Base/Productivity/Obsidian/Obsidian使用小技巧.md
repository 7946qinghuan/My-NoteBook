# Obsidian使用小技巧

## 分屏同步预览和编辑
### 第一步：实现左右分屏

1. 打开你想查看的笔记。
    
2. 鼠标右键点击该笔记顶部的**标签页（Tab）** 或者 **三个点**。
    
3. 在弹出的菜单中选择 **“左右分屏**。
    
4. 此时，你的界面会复制出一个完全相同的标签页，并排在右侧。

### 第二步：联动两个标签页

1. 鼠标右键点击右侧（或左侧）刚刚拆分出来的那个标签页。
    
2. 在菜单中找到并点击 **“关联标签页...” (Link tab...)**。
    
3. 此时界面会弹出一个小列表，显示当前可链接的标签页，**选择你左侧的那个标签页**。
    
4. 链接成功后，两个标签页的右上角都会出现一个**小链条图标 🔗**，表示它们已经成功绑定。
