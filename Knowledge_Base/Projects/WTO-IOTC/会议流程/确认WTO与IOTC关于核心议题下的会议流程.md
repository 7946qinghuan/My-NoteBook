## 四、“会议主题”的统一定义

**推荐定义：一个会议主题代表一场具体会议。**

虚拟谈判模块的操作关系为：

1. 第一步选择议题场景和核心议题。
2. 第二步展示该核心议题下可选的具体会议。
3. 用户只选择其中一场会议。
4. 系统根据所选会议匹配会议流程、参与方和生成内容。

每个会议主题必须包含：

|   |   |
|---|---|
|字段|内容|
|会议主题名称|能够直接说明本场会议讨论什么|
|会议类型|NGR、Commission、SC、CoC、TCAC、SCAF、工作组等|
|会议流程|仅包含本场会议内部的流程|
|会议内容|本场会议需要讨论和决定的事项|
|输入资料|本场会议使用的报告、提案、数据和基础案文|
|资料来源|能够取得上述材料的官方网站、会议页面或文件库|
|会议产出|本场会议最终形成的文本、建议、报告或决定|

**统一处理规则：**

- 前序机构的报告只作为本场会议的输入资料。
- 后续机构只作为本场会议产出的提交方向。
- 不把“工作组 → 委员会 → Commission”写成一场会议的流程。
- 一个会议主题只能匹配一种会议类型和一套单场会议流程。

## 第二部分：RFMO-IOTC

### 五、IOTC 单场会议流程库

#### IOTC-COM：Commission 决议审议会议

1. 主席开场、代表权报告和议程通过。
    
2. 介绍与本议题相关的下设机构报告。
    
3. 提案成员介绍 Resolution 或 Recommendation 草案。
    
4. 各 CPC 陈述立场并逐条讨论案文。
    
5. 必要时开展会中起草或主席磋商。
    
6. 主席测试共识；不能收敛时表决。
    
7. 通过会议报告和相关决定。
    
8. 如通过 Resolution，秘书处进行通知；原则上自通知指定日期起 120 天后生效，成员可在该期间提出异议，其他成员另有 60 天异议窗口。
    

**本场会议产出：**Resolution、Recommendation、Commission 决定或会议报告。

  

#### IOTC-SC：Scientific Committee 科学建议会议

1. 主席开场并通过议程。
    
2. 审议相关工作组报告和国家报告。
    
3. 介绍种群评估、风险分析或方法结果。
    
4. 成员和专家开展科学审议。
    
5. 讨论管理选项、数据缺口和研究需求。
    
6. 形成科学建议并通过 SC 报告。
    

**本场会议产出：**科学建议、管理选项、研究计划和 SC 报告。

  

#### IOTC-SWP：科学工作组会议

1. 主席开场并通过议程。
    
2. 介绍数据、国家文件和研究论文。
    
3. 审议数据质量、方法和模型。
    
4. 开展种群、生态或兼捕风险分析。
    
5. 讨论管理选项和研究优先事项。
    
6. 形成建议并通过工作组报告。
    

**适用会议：**WPTT、WPNT、WPTmT、WPB、WPEB、WPDCS 等。

**本场会议产出：**技术建议、数据需求、研究建议和工作组报告。

  

#### IOTC-TCAC：配额分配标准会议

1. 主席开场并通过议程。
    
2. 介绍分配数据、主席文件和现有方案。
    
3. 讨论分配对象、原则和适用范围。
    
4. 逐项谈判分配标准、权重和调整规则。
    
5. 使用数据或模拟工具比较方案结果。
    
6. 主席汇总分歧和可收敛内容。
    
7. 通过会议报告或分配框架建议。
    

**本场会议产出：**分配框架、主席文本、会议建议和 TCAC 报告。

  

#### IOTC-CoC：履约审查会议

1. 主席开场并通过议程。
    
2. 秘书处介绍 Summary Compliance Report。
    
3. 按 CPC、措施和义务逐项审查。
    
4. CPC 提交说明、补充证据和整改情况。
    
5. 讨论合规状态、能力限制和后续行动。
    
6. 形成整改建议和实施期限。
    
7. 通过 Provisional Compliance Report。
    

**本场会议产出：**Provisional Compliance Report、整改建议和履约状态建议。

  

#### IOTC-WPICMM：履约制度技术会议

1. 主席开场并通过议程。
    
2. 介绍现行 CMM 的执行问题。
    
3. 介绍监测、控制和执法技术方案。
    
4. 讨论制度设计、数据要求和可执行性。
    
5. 修改技术建议或制度文本。
    
6. 通过工作组报告和建议。
    

**本场会议产出：**技术建议、制度修订建议和 WPICMM 报告。

  

#### IOTC-WPSE：社会经济工作组会议

1. 主席开场并通过议程。
    
2. 介绍社会经济数据、指标和研究文件。
    
3. 审议数据口径和评估方法。
    
4. 评估 CMM、配额或捕捞限制的社会经济影响。
    
5. 讨论小规模、生计和沿海渔业政策选项。
    
6. 形成建议并通过 WPSE 报告。
    

**本场会议产出：**社会经济影响评估、政策建议和 WPSE 报告。

  

#### IOTC-SCAF：预算和行政会议

1. 主席开场并通过议程。
    
2. 秘书处介绍预算执行和预算草案。
    
3. 逐项审议会费、支出、项目和行政事项。
    
4. 必要时由小型非正式组处理争议事项。
    
5. 形成预算和行政建议。
    
6. 通过 SCAF 报告。
    

**本场会议产出：**预算建议、行政建议、工作计划建议和 SCAF 报告。

  

#### IOTC-TCMP：管理程序技术会议

1. 主席开场并通过议程。
    
2. 介绍管理目标、MSE 结果和科学建议。
    
3. 讨论参考点、捕捞控制规则和触发条件。
    
4. 比较管理程序方案及其绩效。
    
5. 讨论实施、审查周期和例外情况。
    
6. 形成建议并通过 TCMP 报告。
    

**本场会议产出：**管理程序建议、政策选项和 TCMP 报告。
