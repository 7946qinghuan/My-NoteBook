# VSCode 为 Python 开启类型内联提示配置笔记

本文档用于配置 VSCode 编辑器，开启 Python 代码的变量、函数返回值**内联类型提示**，无需手动写注释，编辑器自动展示代码类型，提升代码可读性、调试效率，适配日常Python开发、项目规范校验场景。

## 一、前置依赖：安装 Pylance 插件

Python 类型内联提示功能依赖 Pylance 语法分析插件，VSCode 默认Python插件无完整的内联提示能力，必须安装此插件。

1. 打开 VSCode 编辑器，点击左侧侧边栏「扩展」图标（或使用快捷键 `Ctrl+Shift+X`）；
    
2. 在扩展搜索框输入 **Pylance**；
    
3. 找到微软官方出品的 Pylance 插件，点击「安装」；
    
4. 安装完成后自动启用，无需额外手动激活，若未生效可重启 VSCode。

补充：安装Pylance后，VSCode会自动将其作为默认Python语言服务，替代原生Python插件的语法分析功能。

## 二、修改配置文件，开启内联类型提示

通过修改 `settings.json` 配置文件，开启变量、函数返回值的可视化内联类型提示。

### 1. 打开配置文件

1. 使用快捷键 `Ctrl+,` 快速打开 VSCode 设置界面；
    
2. 点击设置界面**右上角的「打开设置(JSON)」图标**，进入 `settings.json` 编辑页面。

### 2. 添加核心配置代码

在现有JSON配置内容的末尾（大括号内部），追加以下配置项，两项配置各司其职，可按需开启：

```json
// 开启变量类型的内联提示（核心必备配置，展示变量定义的类型）
"python.analysis.inlayHints.variableTypes": true,

// 开启函数返回类型的内联提示（可选配置，展示函数执行后的返回值类型）
"python.analysis.inlayHints.functionReturnTypes": true
```

### 3. 保存生效

按下 `Ctrl+S` 保存配置文件，无需重启编辑器，打开Python文件即可实时看到内联类型提示效果。

## 三、配置项详细说明

|配置项|作用说明|必要性|
|---|---|---|
|`python.analysis.inlayHints.variableTypes`|自动在代码变量后方，内联展示变量的推导类型（如 int、str、list 等），解决动态语言变量类型模糊的问题|必备（核心需求效果）|
|`python.analysis.inlayHints.functionReturnTypes`|自动在函数定义、调用位置，内联展示函数的返回值类型，快速判断函数输出数据类型|可选，根据开发需求开启|

## 四、常见问题排查

1. **配置后无提示效果**
    
    1. 检查是否安装 Pylance 插件，仅安装Python插件无法生效；
        
    2. 检查JSON配置格式是否正确（逗号分隔、无语法报错），VSCode会实时校验配置语法；
        
    3. 重启 VSCode 编辑器，刷新语言服务。
        
2. **提示文字遮挡代码，观感杂乱**
    
    1. 可关闭非必要的 `functionReturnTypes` 配置，仅保留变量类型提示；
        
    2. 可在设置中搜索「内联提示」，微调提示文字透明度、字体大小。
        
3. **部分变量无类型提示**
    
    1. 动态赋值、泛型变量、未知导入的模块变量，Pylance无法自动推导类型，属于正常现象；
        
    2. 可手动添加类型注解，配合插件实现完整提示。
        

## 五、补充拓展

该配置为**全局配置**，对当前VSCode所有Python项目生效；若需要仅对单个项目生效，可在项目根目录新建 `.vscode/settings.json` 文件，写入相同配置即可。
